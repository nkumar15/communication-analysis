# Admin Dashboard - User Guide

Quick reference for using the admin dashboard interface.

---

## 🏠 Dashboard Overview

After logging in, you'll see the main dashboard with:
- **Statistics Cards**: Total users, active users, pending invitations, managers
- **Welcome Section**: Feature highlights
- **Quick Actions**: Shortcuts to common tasks

---

## 📊 Navigation

### Sidebar Menu
- **🏠 Dashboard** - Overview and statistics
- **👥 User Management** - Manage users and invitations

### User Profile (Top Right)
Click your profile icon to:
- View your name and role
- See your organization
- **Logout**

---

## 👥 User Management

### Users Tab
View all users in your organization:
- **Search**: Type name or email to filter
- **Filter by Role**: Admin / Manager / Member
- **Filter by Status**: Active / Inactive

**User Details Shown:**
- Avatar with user initials
- Name and email
- Role badge (color-coded)
- Status badge (Active/Inactive)
- Last login date

### Pending Invitations Tab
View and manage pending invitations:
- **Only shows pending** - Accepted invitations appear in Users tab
- **Search & Filter**: Same as Users tab
- **Actions**: Resend or Cancel invitations

**Invitation Details Shown:**
- Email address
- Role assignment
- Status (Pending/Expired)
- Sent date
- Expiry date (7 days)

---

## 📧 Inviting Users

1. Click **"+ Invite User"** button (top right)
2. Enter email address (must match your company domain)
3. Role is automatically set to "Manager"
4. Click **"Send Invitation"**

The user will receive an email with an invitation link.

---

## 🔄 Managing Invitations

### Resend Invitation
1. Go to **Pending Invitations** tab
2. Click three-dot menu (⋮) on the invitation
3. Select **"Resend"**

### Cancel Invitation
1. Go to **Pending Invitations** tab
2. Click three-dot menu (⋮) on the invitation
3. Select **"Cancel"**
4. Confirm cancellation

---

## 🎨 Understanding Badges

### Role Badges
- **Purple** - Admin
- **Orange** - Manager
- **Blue** - Member

### Status Badges (Users)
- **Green** - Active
- **Gray** - Inactive

### Status Badges (Invitations)
- **Orange** - Pending
- **Red** - Expired

---

## 🔐 Permissions

**All Users Can:**
- View the Users tab
- See user statistics

**Admins Only Can:**
- View Pending Invitations tab
- Send new invitations
- Resend invitations
- Cancel invitations

---

## 💡 Tips

- **Search is instant** - Results update as you type
- **Combine filters** - Use search + role + status together
- **Tab counts** - Badge shows number of items in each tab
- **Action menus** - Click three dots (⋮) for more options
- **Click outside** - Closes dropdowns and modals

---

## 🚀 Quick Access

**From anywhere:**
- **Sidebar** - Always visible for navigation
- **Profile icon** - Always accessible in top-right
- **Current page** - Highlighted in sidebar

**Keyboard shortcuts:**
- `Esc` - Close modals and dropdowns
- Click outside - Close dropdowns/modals
