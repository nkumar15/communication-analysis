# Authentication & Identity (B2B)

## 1. Context
### Goal
Provide a secure, multi-tenant authentication system using Firebase/GCIP that supports Single Sign-On (SSO) integration (OIDC, SAML) for business customers.

### User Stories
- **As a User**, I want to log in using my corporate credentials (Okta, Google Workspace) via SSO.
- **As a System Admin**, I want to ensure Tenant A cannot access Tenant B's data (Strict Isolation).
- **As a Mobile User**, I want to log in seamlessly using the native app.

### Key Business Rules
**1. Identity Model**:
- **Primary Identifier**: Email Address. (Links users across providers).
- **UID**: Generated by GCIP. (Note: Mobile and Web may produce different UIDs, reconciled by email).

**2. Tenant Isolation**:
- enforced at Database Level via **RLS (Row Level Security)**.
- Every query MUST be scoped by `app.current_tenant_id`.

**3. Verification**:
- Users must have `email_verified: true` to access critical features.

## 2. Architecture
### Authentication Flows
**A. Web (SP-Initiated)**:
1. User enters Email -> Backend resolves IDP Config.
2. User authenticates with IDP (Okta/Google).
3. GCIP returns Firebase ID Token to Frontend.
4. Frontend calls Sync API -> User created in DB.

**B. Mobile (Native)**:
1. App resolves IDP Config via API.
2. App performs OAuth flow directly with IDP.
3. App sends ID Token to Backend (Exchange Endpoint).
4. Backend mints **Custom Firebase Token**.

### Data Security (RLS)
The database enforces isolation via `app.current_tenant_id`.
```python
await rls_service.set_tenant_context(db, tenant_id)
# Only then query execution is allowed
```

## 3. Database Schema
**Schema**: `b2b` (Users table)

| Table Name | Description | Key Columns |
| :--- | :--- | :--- |
| `users` | User Identity | `id`, `email`, `firebase_uid`, `tenant_id`, `role_id` |
| `tenants` | Tenant Config | `id`, `domain`, `oidc_config`, `saml_config` |

## 4. API Reference
| Method | Endpoint | Description | Permission |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/b2b/auth/sync-user` | Link Firebase User to DB User | Public (Auth Token req) |
| `POST` | `/api/b2b/auth/mobile-login` | Exchange IDP Token for Custom Token | Public |
| `POST` | `/api/b2b/auth/sso-config` | Resolve Tenant SSO Config | Public |

## 5. Dependencies
- **Internal**: `services.rls_service`, `services.user_service`
- **External**: Firebase / Google Cloud Identity Platform (GCIP)
