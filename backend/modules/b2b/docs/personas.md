# Personas

## Overview

| Persona | Role | Primary Focus | Key Pages |
|---------|------|---------------|-----------|
| **Alex** | Tenant Owner | Billing, Team Management, Admin | Dashboard, Billing, Team |
| **Sam** | Team Member | Daily tasks, Collaboration | Dashboard, Projects |

---

## Alex (Tenant Owner)

### Profile

| Attribute | Value |
|-----------|-------|
| **Title** | Founder / IT Admin |
| **Experience** | Tech-savvy, manages software for the org |
| **Daily Focus** | Ensuring the team has access, managing costs |
| **Tech Comfort** | High |

### Goals
- Invite team members quickly
- Upgrade/Downgrade subscription plans based on usage
- Configure organization-wide settings (SSO, Security)

### Pain Points Addressed

| Pain Point | How Product Solves It |
|------------|----------------------|
| Manual user onboarding | Email invitation flow with role assignment |
| Unpredictable costs | Clear tiered pricing and invoice history |
| Security compliance | RBAC and Audit logs |

### Key Pages
1. **Billing Settings** – Managing invoices and payment methods
2. **Team Members** – Inviting and managing users
3. **Dashboard** – Overview of tenant health

### Typical Workflow

```
Step 1: Receive Invoice Alert
    ↓
Step 2: Login to Dashboard
    ↓
Step 3: Navigate to Billing Settings
    ↓
Step 4: Download Invoice / Update Card
```

### Success Metrics
- Time to onboard a new user (< 2 mins)
- Zero downtime during plan upgrades

## Sam (Team Member)

### Profile

| Attribute | Value |
|-----------|-------|
| **Title** | Project Manager / Developer |
| **Experience** | Focused on productivity, not admin tasks |
| **Daily Focus** | collaborating on projects |
| **Tech Comfort** | Medium to High |

### Goals
- Access assigned projects
- Collaborate with team members
- Update profile settings

### Pain Points Addressed

| Pain Point | How Product Solves It |
|------------|----------------------|
| No access to tools | Self-service profile management, clear permissions |
| Confusing navigation | Simplified member view (hides admin settings) |

### Key Pages
1. **Dashboard** – Access to projects
2. **Profile** – Personal settings

### Typical Workflow

```
Step 1: Login
    ↓
Step 2: View Dashboard
    ↓
Step 3: Access Domain Feature (e.g. Bank Surveillance)
```

### Success Metrics
- Login speed
- Ease of finding assigned tasks
