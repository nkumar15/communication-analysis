# Demo Script: Sam (Team Member)

## Persona Context
**Sam** is a developer at "Acme Corp". Alex just invited him. He needs to access the Bank Surveillance tool.

## Scenario 1: First Login
**Goal**: Access the workspace.

1.  **Email**: Sam gets "You're invited to Acme Corp".
2.  **Login**: Enters temporary password (or sets new one).
3.  **Dashboard**:
    -   He sees **My Teams** and **My Tasks**.
    -   *Note*: He does **NOT** see "Billing" or "Org Health" (RBAC in action).

## Scenario 2: Updating Profile
**Goal**: Set a friendly avatar.

1.  **Navigation**: Clicks **Profile** (User Icon top right).
2.  **Profile Page**:
    -   Clicks "Change Avatar".
    -   Uploads photo.
    -   Toggles "Dark Mode" (if available).
3.  **Result**: Application theme updates immediately.

## Scenario 3: Accessing Domain Features
**Goal**: Start an investigation.

1.  **Sidebar**: Clicks "Bank Surveillance".
2.  **Transition**: Sidebar changes to Domain-specific navigation (Alerts, Investigations).
3.  **Result**: Sam is now deep in his daily workflow, with the B2B foundation handling the session security invisibly.
