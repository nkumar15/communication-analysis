# Bank Surveillance Platform

> An enterprise-grade communication surveillance platform — demonstrated using real-world bank communication data.

## Overview

This platform transforms raw communication data into actionable compliance insights. Unlike simple dataset explorers, it provides a complete surveillance workflow: from ingestion to alerts, investigations, cases, and regulatory reporting.

**Key Differentiators:**
- 🤖 Multi-Agent AI Analysis (Intent, Policy, Evasion detection)
- 🕸️ Social Graph Intelligence (Clique detection, centrality analysis)
- 🏢 Enterprise Multi-Tenant Architecture (Region/Team isolation)
- 📊 Production-Grade Audit Trail (Regulator-ready exports)

## Target Platform
- [x] Web
- [ ] Mobile (iOS/Android)
- [ ] Backend API Only
